📍 导入后怎么开启「紧急」提醒？
  1. 导入成功后，打开 iPhone「提醒事项」App。
  2. 找到刚导入的提醒（可按日期搜索），点进去。
  3. 点右上角的 信息(i)。
  4. 在「日期与时间」下方，打开 紧急 开关。
  5. 打开后看一眼「日期与时间」——它应自动等于你导出的排班时间（如 08:00 班、提前 60 分就显示 07:00），不用手动改。若显示成"今天 15:00"之类，说明 iPhone 没解析进时间，请改用「iPhone 提醒事项 / 系统闹钟」里的快捷指令方案。
  6. 返回；该条会出现在首页的「紧急」智能列表里，到点会像闹钟一样响。

注：「紧急」是智能列表，不是普通列表，.ics 文件没有对应字段，所以导入时没法自动打开，必须手动开。已设置高优先级(PRIORITY:1)方便你找到它。

iPhone 提醒事项 / 系统闹钟

先说清楚：iPhone 不能直接安装网页生成的未签名快捷指令，所以 .shortcut 文件下载导入这条路走不通（你截图的"无法打开未签名快捷指令"就是苹果的封锁）。

真正能一次创建 60 条提醒的办法是：你在「快捷指令」App 里手动搭一个批量捷径（只需搭一次），之后网页点「⚡ 一键运行…」就会自动把全部排班清单写进剪贴板并唤起该捷径，你点一下运行就全部加进「提醒事项」，日期和时间都是你文件里的。

⚡ 首次设置：在 iPhone 搭一个「批量添加排班提醒」捷径（只需一次）

iOS 26 把动作菜单位置改了，不用在菜单里翻，直接在每个动作的搜索框里打下面括号里的关键词就能找到。清单格式：2026/08/05 07:00[TAB]早班 08:00 上班 · 准备[TAB]提前 60 分钟提醒。

  1. 打开 iPhone「快捷指令」App → 点右上角 + 新建快捷指令。
  2. 搜索框搜 「剪贴板」 → 添加动作 获取剪贴板。
  3. 搜索框搜 「拆分」 → 添加 拆分文本：文本选上一步的剪贴板；分隔符选 新行。
  4. 搜索框搜 「重复」 → 添加 针对每一项重复：输入选上一步的拆分结果。
  5. 在循环里，搜索框搜 「拆分」 → 加 拆分文本：文本选魔法变量 重复项目；分隔符选 制表符（Tab）。
  6. 搜索框搜 「项目」 → 加 从列表中获取项目：
    ⚠️ 最容易错：这个动作自带的输入框（常写着"日期"或"列表"）必须改成上一步「按制表符拆分」的结果。如果显示成 从 日期… 获取 就是接错了，会报"索引超出范围"。正确应为 从 拆分文本… 获取。
    输入改对后，「索引」填 1 → 点结果，选「设为变量」→ 命名 日期时间。
  7. 同样再加两次 从列表中获取项目（输入都选「按制表符拆分的结果」）：索引 2 → 设为变量 标题；索引 3 → 设为变量 备注。
  8. 搜索框搜 「提醒事项」 → 加 添加提醒事项：
    • 标题：选变量 标题
    • 备注：选变量 备注
    • 打开 提醒 开关
    • 时间：点日期框 → 选魔法变量 日期时间（不是"提醒日期"，就是那个文本变量）
  9. 点右上角「完成」，命名为 批量添加排班提醒。

不用设"提醒日期"变量：直接把文本变量 日期时间 填进「添加提醒事项」的到期日，iOS 会自动把它解析成日期。如果它死活不认，见下方的「极简版」。

🛟 极简版（如果上面搞不定，用这个）

上面步骤太多容易接错。极简版每行只有一个时间，完全不用「从列表中获取项目」和索引，但所有提醒标题统一为"上班提醒"。

  1. 在 iPhone「快捷指令」App 新建快捷指令，命名为 批量添加排班提醒。
  2. 搜索框搜 「剪贴板」 → 加 获取剪贴板。
  3. 搜索框搜 「拆分」 → 加 拆分文本：文本选剪贴板；分隔符选 新行。
  4. 搜索框搜 「重复」 → 加 针对每一项重复：输入选拆分结果。
  5. 在循环里，搜索框搜 「提醒事项」 → 加 添加提醒事项：标题写死 上班提醒，打开 提醒 开关，到期日选魔法变量 重复项目。
  6. 完成。

使用极简版时，先点网页「📋 仅复制清单」，但它默认复制的是带标题的 3 列。你需要先把清单改成每行只有时间（如 2026/08/05 07:00），或告诉我，我把网页加一个「仅复制时间（极简版）」按钮。

关于「紧急」开关：快捷指令目前还不能自动勾「紧急」，但日期和时间已经自动填对。运行完批量捷径后，你只需在「提醒事项」App 里把每条点开 → 信息(i) → 打开紧急即可，不用改时间。下面「时钟 App」是兜底：最稳、可自定义铃声、锁屏也持续响。
