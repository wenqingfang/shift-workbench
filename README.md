# 班次闹钟工作台

一个移动端优先的排班闹钟工作台（PWA）。在月历上排班，导出 `.ics` 导入手机系统日历，由系统日历负责准时响铃（锁屏也响）。网页本身不直接写系统闹钟，这是 iOS/Android 的限制。

## 功能
- 月历排班：点日期选班次（上午 / 下午 / 晚班 / 休息，可自定义）
- 班次配置：名称、上班时间、颜色、是否闹钟
- 提前量：默认提前 60 分钟，可改
- 连点模式：选好班次后批量点日期快速排班
- 排班导入：文本 / 循环规则 / CSV / 备份 JSON
- 导出 `.ics`：带 `VALARM` 提醒，手机日历打开即导入
- 数据本地存储，支持备份 / 恢复 / 清空

## 部署（GitHub Pages）
见下方给用户的命令。部署后手机 Safari 打开 → 分享 → 添加到主屏幕，即为主屏 App。

## iPhone 使用
1. Safari 打开部署后的网址 → 分享 → 添加到主屏幕
2. 排好班 → 点「导出到手机日历」→ 分享面板选「日历」导入
3. 系统日历负责锁屏响铃
